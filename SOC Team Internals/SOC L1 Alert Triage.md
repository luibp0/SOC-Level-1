# SOC L1 Alert Triage

## Overview

This room focuses on the alert triage process performed by Level 1 SOC Analysts. It explains how security alerts are reviewed, analyzed, classified, and prioritized to determine whether they represent real threats and require further investigation.

## Alert Triage Process

- **Review the Alert:** Examine the information provided by the security tool.
- **Gather Context:** Collect relevant information about users, systems, IP addresses, and events.
- **Validate the Alert:** Determine whether the detected activity is legitimate or suspicious.
- **Classify the Alert:** Identify whether the alert is a true positive or false positive.
- **Determine Severity:** Evaluate the potential impact and urgency of the alert.
- **Escalate if Necessary:** Send confirmed or complex threats to higher-level SOC analysts for further investigation.

## Alert Classification

SOC analysts commonly classify alerts as:

- **True Positive:** A real security threat has been detected.
- **False Positive:** Legitimate activity was incorrectly identified as malicious.
- **True Negative:** Normal activity was correctly identified as safe.
- **False Negative:** Malicious activity occurred but was not detected.

## SOC L1 Responsibilities

A Level 1 SOC Analyst is typically responsible for:

- Monitoring security alerts
- Performing initial investigations
- Gathering relevant evidence
- Identifying suspicious activity
- Prioritizing alerts
- Documenting investigation findings
- Escalating confirmed threats when necessary

## Skills Learned

- Performing basic alert triage
- Analyzing security alerts
- Distinguishing between true and false positives
- Prioritizing alerts based on severity
- Gathering context during investigations
- Documenting investigation results
- Understanding when an alert should be escalated

## Key Takeaway

Alert triage is a core responsibility of a Level 1 SOC Analyst. Effective triage helps identify real threats, reduce unnecessary investigations, prioritize critical alerts, and ensure serious incidents are escalated appropriately.
