# SOC Workbooks and Lookups

## Overview

This room focuses on the reference materials and documentation used by SOC analysts during investigations. It explains how workbooks,
identity inventories, asset inventories, and network information help analysts quickly understand the environment and investigate alerts more efficiently.

## Topics Covered

- SOC Workbooks
- Identity Inventory
- Asset Inventory
- Network Diagrams
- User Information
- Host Information
- Network Subnets
- Services and Ports
- Investigation Lookups
- SOC Documentation

## SOC Workbooks

SOC workbooks provide analysts with important information about the organization and its environment.

They may include:

- User identities
- Employee roles
- System information
- Asset ownership
- Network locations
- Services and ports
- Subnets
- Business functions

## Common Lookups

During an investigation, SOC analysts may need to look up:

- **Users:** Job role, department, location, and access privileges
- **Assets:** Hostname, purpose, owner, and operating system
- **Networks:** Subnets, network zones, and communication paths
- **Services:** Ports, protocols, and their intended purpose

## Why Workbooks Are Important

Workbooks help analysts:

- Add context to security alerts
- Identify affected users and systems
- Understand normal network behavior
- Recognize unusual activity
- Investigate incidents faster
- Make better escalation decisions

## SOC L1 Responsibilities

A Level 1 SOC Analyst should:

- Use available documentation during investigations
- Verify user and asset information
- Understand the network environment
- Compare alert activity with expected behavior
- Document relevant findings
- Escalate suspicious activity when necessary

## Skills Learned

- Using SOC workbooks during investigations
- Performing identity and asset lookups
- Understanding network diagrams
- Identifying services and ports
- Adding context to security alerts        
- Improving investigation accuracy

## Key Takeaway

SOC workbooks and lookups provide valuable context during security investigations. They help analysts understand users, systems, and network activity before making decisions about an alert.
