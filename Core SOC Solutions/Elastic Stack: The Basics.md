## Elastic Stack Components

The Elastic Stack consists of several core components:

- **Elasticsearch:** Stores, indexes, and searches large amounts of data.
- **Logstash:** Collects, processes, and transforms data before sending it to Elasticsearch.
- **Beats:** Lightweight data shippers that send logs and other data to the Elastic Stack.
- **Kibana:** Provides an interface for searching, analyzing, and visualizing data.

## Kibana Discover

The Discover feature allows SOC analysts to explore and investigate log data.

Key features include:

- Search Bar
- Fields Pane
- Index Patterns
- Time Filters
- Event Timeline
- Filters

## Kibana Query Language (KQL)

KQL is used to search and filter data in Kibana.

It supports:

- Free-text searches
- Field-based searches
- `AND`, `OR`, and `NOT` operators
- Filtering specific values
- Combining multiple search conditions
