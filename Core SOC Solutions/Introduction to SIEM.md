# Introduction to SIEM

## Overview

This room introduces Security Information and Event Management (SIEM) and its role in a Security Operations Center (SOC).
It explains how SIEM solutions collect, centralize, analyze, and correlate security logs to help analysts detect and investigate suspicious activity.

- Security Monitoring
- Dashboards and Alerts

## Core SIEM Capabilities

SIEM solutions provide several important capabilities:

- **Log Collection:** Gather security logs from multiple systems and devices.
- **Centralization:** Store logs in a central location for easier analysis.
- **Normalization:** Convert different log formats into a consistent structure.
- **Correlation:** Connect related events from multiple sources.
- **Detection:** Identify suspicious activity using detection rules.
- **Visualization:** Display security information through dashboards and reports.

## Common Log Sources

SIEM solutions can collect logs from:

- Windows and Linux systems
- Firewalls
- Web servers
- VPN services
- Applications
- Authentication systems
- Network devices
- Endpoint security solutions

## Log Ingestion Methods

Common methods used to send data to a SIEM include:

- Agents and Forwarders
- Syslog
- Manual Upload
- Port Forwarding

## Detection Rules

SIEM detection rules can identify suspicious activity such as:

- Security logs being cleared
- Suspicious process execution
- Unauthorized USB devices
- Unusual authentication activity
- Large outbound data transfers
- Potential data exfiltration

## Key Takeaway

SIEM provides SOC analysts with centralized visibility across an organization's environment. By collecting and correlating security logs, SIEM solutions help analysts detect suspicious activity, investigate alerts, and identify potential security incidents.
