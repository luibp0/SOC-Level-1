# Core SOC Solutions

## Overview

This module focuses on the core technologies and solutions used by Security Operations Center (SOC) teams to monitor, detect, investigate, and respond to security threats.

## Topics Covered

- Endpoint Detection and Response (EDR)
- Security Information and Event Management (SIEM)
- Splunk
- Elastic Stack
- Security Orchestration, Automation and Response (SOAR)
- Security Monitoring
- Threat Detection and Investigation

## Key Takeaway

Core SOC solutions provide analysts with the visibility and tools needed to collect security data, detect suspicious activity, investigate alerts, and respond to security incidents efficiently.
