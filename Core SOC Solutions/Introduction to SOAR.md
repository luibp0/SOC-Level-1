# Introduction to SOAR

## Overview

This room introduces Security Orchestration, Automation, and Response (SOAR) and its role in Security Operations Center (SOC) environments. It explains how SOAR helps analysts connect security tools, automate repetitive tasks, and respond to security incidents more efficiently.

## Core SOAR Capabilities

SOAR provides several important capabilities:

- **Orchestration:** Connects and coordinates different security tools such as SIEM, EDR, firewalls, and threat intelligence platforms.
- **Automation:** Automatically performs repetitive investigation and response tasks.
- **Response:** Helps analysts take appropriate actions against identified threats.
- **Case Management:** Organizes alerts, investigation details, evidence, and response actions.

## SOAR Playbooks

A playbook defines a sequence of steps that should be performed when a specific security alert or incident occurs.

A typical playbook may include:

- Receive a security alert
- Gather additional information
- Check threat intelligence
- Analyze related security events
- Determine whether activity is malicious
- Perform containment actions
- Create or update a case ticket
- Escalate the incident when necessary

## Automation vs Manual Actions

SOAR workflows can contain both:

- **Automated Actions:** Tasks performed automatically by the SOAR platform.
- **Manual Actions:** Tasks that require analyst review, validation, or approval.

This allows organizations to automate repetitive tasks while keeping analysts involved in important security decisions.
