# Introduction to EDR

## Overview

This room introduces Endpoint Detection and Response (EDR) and its role in Security Operations Center (SOC) environments. It explains how EDR solutions provide visibility into endpoint activity, detect suspicious behavior, and allow analysts to respond to potential threats.

## Topics Covered

- Endpoint Detection and Response (EDR)
- Endpoint Monitoring
- Threat Detection
- Behavioral Analysis
- Process Monitoring
- File Activity
- Registry Activity
- Indicators of Compromise (IoCs)
- Endpoint Investigation
- Incident Response

## Core EDR Capabilities

EDR solutions provide several important capabilities:

- **Visibility:** Monitor processes, files, registry changes, and user activity on endpoints.
- **Detection:** Identify malicious or suspicious behavior using behavioral analysis and detection techniques.
- **Investigation:** Provide detailed endpoint information to help analysts understand suspicious activity.
- **Response:** Allow analysts to take action against identified threats.

## Common EDR Response Actions

SOC analysts can use EDR solutions to:

- Isolate compromised endpoints
- Terminate malicious processes
- Quarantine malicious files
- Investigate process activity
- Collect Indicators of Compromise (IoCs)
- Analyze suspicious endpoint behavior

## Endpoint Investigation

During an EDR investigation, analysts may examine:

- Process execution and parent-child relationships
- Suspicious files and file paths
- Network connections
- Registry modifications
- User activity
- IP addresses and domains
- File hashes
