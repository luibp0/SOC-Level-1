# Cyber Defence Frameworks

## Overview

This module introduces common cybersecurity frameworks used by defenders to understand, analyze, and respond to cyber attacks.

## Topics Covered

- Cyber Kill Chain
- Unified Kill Chain
- MITRE ATT&CK
- Threat Modeling
- Cyber Analytics Repository (CAR)
- Adversary Tactics, Techniques, and Procedures (TTPs)

## Skills Learned

- Understand the stages of cyber attacks
- Map attacker behavior to MITRE ATT&CK
- Identify Tactics, Techniques, and Procedures (TTPs)
- Use defensive frameworks to analyze threats
- Improve detection and incident response
