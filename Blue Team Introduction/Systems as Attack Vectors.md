# Systems as Attack Vectors

## Overview

This room focuses on how attackers target computer systems, applications, and services to gain unauthorized access or compromise an organization. It introduces common system vulnerabilities, attack techniques, and defensive measures used by Blue Teams.

## Topics Covered

- System-Based Attacks
- Vulnerabilities
- Misconfigurations
- Unpatched Systems
- Weak Credentials
- Malware
- Exploitation
- Privilege Escalation
- System Hardening
- Patch Management

## Common Attack Vectors

- **Unpatched Software:** Exploiting known vulnerabilities in outdated software.
- **Misconfigurations:** Taking advantage of insecure system or service configurations.
- **Weak Credentials:** Using weak, default, or compromised passwords.
- **Malware:** Using malicious software to compromise systems.
- **Exploitation:** Taking advantage of vulnerabilities to gain unauthorized access.
- **Privilege Escalation:** Attempting to gain higher-level permissions after initial access.

## Defensive Measures

Blue Teams can reduce system-related risks through:

- Regular patching and updates
- System hardening
- Strong authentication
- Vulnerability management
- Endpoint protection
- Security monitoring
- Least privilege access

## Skills Learned

- Identifying common system attack vectors
- Understanding how vulnerabilities can be exploited
- Recognizing the risks of system misconfigurations
- Understanding the importance of patch management
- Applying basic system security practices

## Key Takeaway

Systems can become attack vectors when vulnerabilities, weak configurations, or outdated software are present. Proper patching, hardening, access control, and continuous monitoring help reduce the attack surface.
