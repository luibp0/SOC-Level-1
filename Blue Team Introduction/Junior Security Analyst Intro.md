# Junior Security Analyst Intro 

## Overview

This module introduces the role of a Junior Security Analyst working in a Security Operations Center (SOC). It covers the basic responsibilities of a SOC analyst, security monitoring, alert investigation, and responding to suspicious activity.

## Topics Covered

- Security Operations Center (SOC)
- Junior Security Analyst Responsibilities
- Security Monitoring
- Alert Investigation
- Suspicious Login Activity
- IP Reputation Analysis
- Basic Incident Response
- Firewall Actions

## Practical Experience

During the practical exercises, I worked with security alerts such as:

- Successful SSH login from a suspicious IP address
- Unauthorized login attempts
- Investigation of suspicious IP addresses
- Checking IP reputation
- Blocking malicious IP addresses using firewall rules

## Tools & Resources

- SIEM
- Firewall
- AbuseIPDB
- Cisco Talos Intelligence

## Skills Learned

- Monitoring security alerts
- Performing basic alert triage
- Investigating suspicious IP addresses
- Using threat intelligence sources
- Identifying potentially malicious activity
- Taking basic containment actions

## Key Takeaway

A Junior Security Analyst is responsible for monitoring security events, investigating alerts, identifying potential threats, and escalating or responding to incidents when necessary.
